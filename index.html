What is Mathematical Language?

Mathematical language is a way of expressing ideas using numbers, symbols, variables, and mathematical terms.

Common Mathematical Symbols

Symbol Meaning
+Addition
−Subtraction
× or ·Multiplication
÷ or /Division
=Equal to
≠Not equal to
>Greater than
<Less than
≥Greater than or equal to
≤Less than or equal to
√Square root
∛Cube root
ΣSigma / Summation
x, y, zVariables

Example

5 + 3 = 8

The symbol + means addition, and = means equal to.

Definition

A mathematical expression is a combination of numbers, variables, and mathematical operations.

x + 10

Here, x is the variable and 10 is a constant.

Verbal Phrase to Mathematical Expression

Verbal Phrase Expression
The sum of a number and 10 x + 10
The difference of a number and 5 x − 5
The product of 10 and a number 10x
The quotient of a number and 50 x / 50
One-fifth of a number x / 5
Three-fourths of 500 (3/4)(500) = 375
The sum of two numbers less 11 x + y − 11
Double the quantity of sales less taxes 2x − y
The difference of gross sales less taxes x − y
A number subtracted from 8 8 − x
Remember: "A number subtracted from 8" is 8 − x, not x − 8.

What is a Set?

A set is a well-defined collection of distinct objects. The objects in a set are called elements or members.

A = {A, E, L, X}

The elements of set A are A, E, L, and X.

Fundamental Number Sets

Set Definition Example
ℕ Natural / Counting Numbers {1, 2, 3, 4, ...}
W Whole Numbers {0, 1, 2, 3, ...}
ℤ Integers {..., −2, −1, 0, 1, 2, ...}
ℚ Rational Numbers 1/2, 0.75, 3
𝕀 Irrational Numbers √2, π
ℝ Real Numbers Rational and irrational numbers

Examples of Sets

Set of counting numbers greater than 5 but less than 10:

N = {6, 7, 8, 9}

Set of whole numbers greater than 0 but less than or equal to 6:

W = {1, 2, 3, 4, 5, 6}
Note: Some textbooks include 0 in the natural numbers. Your notes use ℕ = {1, 2, 3, ...}.

Definition

Set-builder notation describes a set by stating the condition that its elements must satisfy.

{ x ∈ ℕ | 10 < x < 15 }

Read as: The set of all natural numbers x such that x is greater than 10 but less than 15.

Example 1

Set of all natural numbers greater than 10 but less than 15.

{11, 12, 13, 14}

Example 2

Set of all counting numbers greater than or equal to 5 but less than or equal to 10.

{ x ∈ ℕ | 5 ≤ x ≤ 10 }

Roster form: {5, 6, 7, 8, 9, 10}

Symbols: ∈ means "is an element of." The vertical bar | means "such that."

1. Well-Defined Set

A set whose elements are clearly identified without doubt.

A = {1, 2, 3, 4}

2. Empty Set

A set with no elements. Also called a null set.

A = ∅ or A = { }

3. Finite Set

A set with a limited number of elements.

A = {1, 2, 3, 4, 5}

4. Infinite Set

A set with endlessly continuing elements.

W = {0, 1, 2, 3, ...}

5. Universal Set

The set containing all objects or elements being considered in a discussion.

U = {1, 2, 3, 4, 5, 6, 7}

6. Equal Sets

Two sets are equal if they contain exactly the same elements.

A = {1, 2, 3, 4}
B = {1, 2, 3, 4}
∴ A = B

7. Equivalent Sets

Two sets are equivalent if they have the same number of elements, even if their elements are different.

A = {1, 2, 3, 4}
B = {A, B, C, D}
∴ A and B are equivalent

Subset (⊆)

A set A is a subset of B if every element of A is also an element of B. A can be equal to B.

A = {1, 2, 3}
B = {1, 2, 3, 4, 5}
A ⊆ B

Proper Subset (⊂)

A is a proper subset of B if all elements of A are in B, but A is not equal to B.

A = {1, 2, 3, 4}
B = {1, 2, 3, 4, 5, 6, 7}
A ⊂ B
Difference: A subset may be equal to the other set. A proper subset must be smaller than the other set.

Example from your notes

A = {1, 2, 3, 4, 5}

B = {1, 2, 3, 4, 5, 6, 7}

A ⊂ B

What is a Venn Diagram?

A Venn diagram is a visual representation of sets using circles. It shows relationships between sets.

Example

A = {1, 2, 3, 4}

B = {2, 3, 5, 6}

Set Operations in the Diagram

A ∩ B = {2, 3}

Intersection: The elements common to both A and B.

A ∪ B = {1, 2, 3, 4, 5, 6}

Union: All elements in A or B or both.

Remember: The overlapping part is the intersection. The two circles together represent the union.

1. Set Intersection (∩)

The set of elements common to both A and B.

A = {1, 2, 3, 4}
B = {2, 3, 5, 6, 7}

A ∩ B = {2, 3}

2. Set Union (∪)

The set of all elements belonging to A or B or both. Repeated elements are written only once.

A = {1, 2, 3, 4}
B = {3, 4, 5}

A ∪ B = {1, 2, 3, 4, 5}

3. Disjoint Sets

Two sets are disjoint if they have no common elements.

A = {1, 2, 3}
B = {4, 5, 6}

A ∩ B = ∅
Remember: Intersection means common elements. Union means combine all elements without duplicates.

Universal Set (U)

The universal set contains all elements being considered in a problem.

U = {1, 2, 3, 4, 5, 6, 7}

Set Complement (A′)

The complement of A is the set of all elements in U that are not in A.

U = {1, 2, 3, 4, 5, 6, 7}
A = {1, 2, 3, 4}

A′ = {5, 6, 7}

Another Example

If U = {1, 2, 3, 4, 5} and B = {2, 3, 5}, then:

B′ = {1, 4}
Tip: To find the complement, start with the universal set and remove the elements that belong to A.

What is Reasoning?

Reasoning is the process of using facts, information, and observations to reach a conclusion.

Example

Fact 1: All students in the class have an ID.

Fact 2: Juan is a student in the class.

Conclusion: Juan has an ID.

Important Parts

  • Facts or information
  • Observations
  • Logical thinking
  • Conclusion

Definition

Deductive reasoning starts with a general rule and applies it to a specific situation.

Example 1

General statement: All humans are mortal.

Specific statement: Socrates is a human.

Conclusion: Therefore, Socrates is mortal.

Example 2: Mathematics

1. All even numbers are divisible by 2.
2. 8 is an even number.
3. Therefore, 8 is divisible by 2.
General → Specific
Key idea: Deductive reasoning applies a general rule to a specific case.

Definition

Inductive reasoning starts with specific observations and develops a general conclusion.

Example 1

1. The sun rose in the east yesterday.
2. The sun rose in the east today.
3. Therefore, the sun will probably rise in the east tomorrow.

Example 2: Mathematics

1. 2 + 2 = 4
2. 4 + 4 = 8
3. 6 + 6 = 12
4. Therefore, adding an even number to itself produces an even number.
Specific → General
Key idea: Inductive reasoning gives a probable conclusion, not a guaranteed one.
